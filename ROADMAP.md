# Implementation roadmap

1. **Built.** Responsive shell, three interactive fretboard lessons, note identification, daily sequencing, local progress, exploration and offline use. A GitHub Pages workflow is ready for deployment.
2. **Built.** Guided interval comparison, a scale builder for D major and D natural minor, and daily sessions that pair new skills with spaced review. Connected pentatonic positions and listening prompts remain opportunities.
3. **Play through the changes.** Chord construction, keys, progressions and CAGED, with practical tasks for rhythm, lead and improvisation. Add rhythm and structured ear exercises.
4. **Optional future work.** Explore microphone or audio-interface input if it makes practice more useful. Keep tap and listening alternatives available.
