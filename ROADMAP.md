# Implementation roadmap

1. **Built.** Responsive shell, three interactive fretboard lessons, note identification, daily sequencing, local progress, exploration and offline use. A GitHub Pages workflow is ready for deployment.
2. **Built.** Guided interval comparison, a scale builder for D major and D natural minor, and daily sessions that pair new skills with spaced review. Connected pentatonic positions and listening prompts remain opportunities.
3. **Built.** Triad workshop and chord-building checks, plus a progression workshop that contrasts notes in the key with notes in the current chord.
4. **Built.** Match heard intervals on the fretboard and compare attempts with the target. Listening checks work within daily practice and offer visual hints.
5. **Next.** Connect chord tones to playable inversions and CAGED shapes, then build rhythm work into short improvisation tasks.
6. **Optional future work.** Explore microphone or audio-interface input if it makes practice more useful. Keep tap and listening alternatives available.
